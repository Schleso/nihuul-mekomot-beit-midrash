# Seating Management System

## Overview
The Seating Management System is designed to facilitate the management of seating arrangements in various events at Beit Midrash. This system allows users to efficiently allocate seats, manage reservations, and ensure optimal seating comfort for all participants.

## Features
- **User Management**: Handles user registrations and profiles.
- **Seat Allocation**: Dynamically allocates seats based on user preferences and availability.
- **Reservation Management**: Allows users to reserve seats for specific events.
- **Reporting**: Generates reports on seat usage and availability.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Schleso/nihuul-mekomot-beit-midrash.git
   ```
2. Navigate to the project directory:
   ```bash
   cd nihuul-mekomot-beit-midrash
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the application:
   ```bash
   npm start
   ```

## Usage
- Users can log in to the system to manage their reservations.
- Admins can oversee the entire seating management process.
